# Laravel Perpustakaan

Repository tugas Laravel 12 Pertemuan 05.

Implementasi tugas utama: CRUD Member berbasis Eloquent dan pencarian nama anggota.

## Isi tugas
- CRUD Member
- Validasi StoreMemberRequest
- Pagination 10 data per halaman
- Search berdasarkan nama
- Search tetap terbawa saat pagination

> Repository ini berisi kode tugas. Untuk menjalankannya, gunakan project Laravel 12 yang sudah dibuat sesuai praktikum sebelumnya, lalu jalankan migration dan `php artisan serve`.
